# Sims4 PoseBox - Backend

Spring Boot 기반으로 개발 중인 Sims4 PoseBox 백엔드 프로젝트입니다.
Sims4의 다양한 포즈들을 인원별, 태그별로 쉽게 검색할 수 있는 사이트로 계획하고 있습니다.

현재 인증(Authentication) 기능을 중심으로 구현하고 있으며, Spring Security + JWT로 진행하고 있습니다.

## 기술 스택

* Java 17
* Spring Boot
* Spring Data JPA
* MySQL
* JWT (JJWT)
* BCrypt

## 구현 기능

* 회원가입
* 로그인
* BCrypt 비밀번호 암호화
* JWT 발급
* JWT 검증

## 진행 예정

* Spring Security 적용
* JWT Filter 구현
* Refresh Token
* OAuth (Google Login)
